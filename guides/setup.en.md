# Bing Webmaster setup

1. Open [Bing Webmaster Tools](https://www.bing.com/webmasters) and verify your site.
2. Go to Settings → API Access and generate an API Key.
3. In Deploy → Toolbox → Bing Webmaster → Configure, paste the key and save.
4. After install + enable, query sites, submit URLs, and view crawl stats.
